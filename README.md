# Experiment 3 – Add Interactivity to App – Input and Forms

## Aim

To develop a Flutter application that displays a predefined list of products and allows users to search and filter the products using input widgets.

## Description

This experiment demonstrates the development of an interactive Product Search application using Flutter and Dart.

The application uses a reusable product list and a **TextField** input widget to allow users to search for products. The product list is dynamically filtered based on the text entered by the user.

The application uses:

- **StatefulWidget** to manage changing application state
- **TextEditingController** to read the user's search input
- **TextField** to accept search input
- **ListView.builder** to display products dynamically
- **Card** and **ListTile** widgets to display product information
- **Dynamic filtering** to show matching products

The application provides three main states:

- **Initial screen** – Displays all predefined products
- **Search screen** – Displays products matching the entered search text
- **No-result screen** – Displays a message when no matching product is found

## Technologies Used

- Flutter
- Dart
- StatefulWidget
- TextField
- TextEditingController
- ListView.builder
- Card
- ListTile
- Dynamic Filtering
- Material Design
